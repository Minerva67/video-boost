02

剪辑师视角：每个图形要过的七道关

先想「这里切到什么画面」，再想用哪个组件

视角 1 · 功能

这张图做什么用？

解释耳朵接不住的结构
证明让人相信是真的
重置注意力太久没有变化
三种都不是 → 不加图，人保持全屏。观点、情绪、过渡、金句都属于这一类。
视角 2 · 素材等级

剪辑师会切到什么画面？从高往低找

1
真实素材
新闻 / 官网截图（划出那句话）、真实照片、产品真实界面、真品牌 logo
2
演示
把口播说的操作真的演一遍：指令 → 步骤 → 产出物
3
数据图
数字有对比或变化才画
4
文字卡
只给演不出来的抽象概念

用第 3、4 级必须写出为什么上不去，「方便」不算理由。口播提到真实存在的东西（新闻、报告、公司、产品、地方、人群），先试第 1 级。

视角 3 · 一屏一事

一个画面只讲一件事

  • 复杂内容按口播顺序逐项进入，不一次摆出整张表
  • 出现空格子等着填、大片留白，就拆开或换真实素材
  • 有一个明确的焦点：荧光笔、圈注，或唯一的大数字
  • 卡片不复述口播：关掉声音，这张图给了耳朵拿不到的东西吗？
视角 4 · 节奏

什么时候出、停多久、什么时候走

  • 图形里同一个画面状态停 6–8 秒以内，之后要有新元素、滚动或划重点
  • 人单独出镜是喘气和建立信任；超过约 30 秒没有任何变化，补一处
  • 入点对准关键词的第一个字；出点等这句话说完，不压句尾
  • 全片 4–6 个图形就够，宁少勿滥
视角 5 · 强调手段

不止加图

  • 推近：结构转折、关键判断，全片 3–4 处以内
  • 硬切放大：只给开头钩子，最多 1 次
  • 荧光笔 / 圈注：证据里那个数字，每个画面最多 2 处
  • 回到全屏：观点、情绪、金句；不为了「有东西」硬塞图
视角 6 · 真实与口径

真实素材的底线

  • 截图前读原文，确认数字真的在页面上
  • 画面上写来源名和日期，地址栏写域名
  • 只佐证口播说过的事，不引入新观点；地点、时间段、人群要对得上
  • 公开图只用 CC0 / CC BY / CC BY-SA / 公有领域，署名照抄
  • 不截登录页、付费墙、个人账号；示意界面标「示意」
视角 7 · 审片（渲染草稿之后，正式渲染之前）

独立的「剪辑师」子 agent，只看拼图和台本，逐段回答

  1. 这个画面关掉声音还成立吗？给了耳朵拿不到的东西吗？
  2. 能不能换成更高一级的素材（真实网页、照片、真实界面）？
  3. 是不是一屏塞了好几个想法？有没有空格子、大片留白、整张表一次摆出？
  4. 一眼能看出该看哪里吗？
  1. 提到的品牌、产品有没有带真 logo？
  2. 有没有业余感：装饰性的图、每句都有特效、字墙、挡脸、压字幕？
  3. 全片节奏：哪里太久没变化，哪里太挤？

结论只有两种：过，或打回并写明理由。打回的改完重新拼图复审，全部通过才出正式版。

03

运镜与机位

人永远贴底居中，不缩到角落

五种机位

full 全屏人是内容：钩子、观点、过渡、收尾
split 让位人 58%，图形区约 540px；只在图形承载信息时
dense 密集人 50%，多出的空间放第二层可视化，不放大字
push 慢推1.00→1.06，关键判断、回顾
punch 硬切放大 1.14，只给钩子金句

移动规则

  • 让位要比图形早到：只往前找停顿
  • 回全屏、推近都吸到说话的停顿里，不在词中间动
  • 两个图形间隔不到 4 秒，中间不回全屏，避免一缩一放
  • 平台界面会盖住边角：进度标和 logo 在 150px 以下，字幕底边距 15–20%
04

Eval 标准

门槛 → 自动检查 → 人工评分；每一条都能追到你拍过板的决定

编号检查什么怎么判为什么有这条
A 门槛：任何一项不过 = 不交付
A1成片时长 = 原片相差 ≤ 0.05 秒只加不改
A2渲染稳定HyperFrames lint 0 错误无闪屏、无错位
A3有语音就有字幕每段发声被字幕覆盖 ≥ 50%字幕红线（原片自带字幕时不适用）
A4没语音不出字幕每屏至少 0.15 秒落在发声区字幕红线
A5字幕节奏不到 1 秒或超过 9 字/秒的屏 ≤ 10%竖屏 ≤10 字/屏
B 内容
B1卡片不复述口播图形文字和同时段字幕的重合率，平均 ≤ 45%「你是把他说的话又可视化了」
B2口播外的数字有来源没来源就失败；示意界面里的数字人工确认示意 ≠ 编造
B3示意界面标「示意」示意类组件必须带标注「可以示意」的前提
B4相邻不同版式间隔不到 4 秒的两个图形不能同一组件版面轮换
B5图形密度覆盖 30–75% 时长，每分钟 1–4 个太密 vs 只留 4–6 个
B6单段 ≤ 20 秒超过记提醒，承接型可接受划段规则
C 运镜
C1镜头移动落在停顿让位、回全屏在说话间隙 ±0.15 秒内不在词中间动
C2不一缩一放全屏不到 4 秒又让位记提醒运镜规则
C3图形在场人一定让位图形 35% / 65% / 90% 处都必须是让位不挡脸
C4硬切只给钩子≤ 1 次，且在前 15%punch 规则
C5人单独在场占比25–60%「人是内容」
C6让位先于图形入场镜头开始让位不晚于图形出现落位要早于图形
E 剪辑（剪辑师视角的自动部分）
E1素材等级文字卡不超过一半，且至少一个真实素材或演示盲测片全是表格和文字卡
E2图形不静止一个图形里超过 8 秒没有任何动作记提醒单个画面停 5–6 秒最好读
E3全屏不冷场人单独出镜、没图也没推近，超过 30 秒记提醒人脸与画面约 20–40 秒交替
E4品牌带真 logo图形里出现品牌名却没带 logo 记提醒你认可「加真 logo」那版（待验证分支）
T / S 字号与安全区（无头浏览器实测）
T1字号都在阶梯上只允许 22 / 28 / 36 / 54 / 96 / 140「字整体偏大、层级乱」
T2一个图形 ≤ 3 档阅读字号4 档提醒，5 档以上失败层级清楚
T3没有小于 22px 的字动画中途的缩放不算手机可读下限
T4字幕是最大的阅读文字比字幕大的元素每图最多 1 个BBC 字幕规范
T5最小字号只给来源和标签其余小字 ≤ 25%层级规则
T6文字没被裁掉一半文字框越出容器即失败你截图指出简历卡被切
S1避开平台界面小红书上 150 / 下 200px（可切抖音、Reels、Shorts）平台安全区
R 字幕（对照你的《字幕增强 Eval》红线；原片自带字幕时只查不出现双字幕）
R0不出现双字幕原片有字幕时我们的必须关TS-11
R11–R13时长与同步单屏 ≤ 7 秒；不晚于语音；起止偏差 ≤ 200ms 的屏 ≥ 95%R-11 / R-12 / R-13
R15–R21版式单行；字号 3–4% 画面高；居中、底边距 15–20%R-15 / R-16 / R-19–21
R24–R35不打架、不断词不压图形文字；数字和单位、专名不拆屏；不以挂空的「的 / 和」结尾R-24 / R-27–30 / R-35
H 人工评分（1–5 分，依据写到秒）
H1静音测试5 分：每张图都给了耳朵拿不到的东西；1 分：图上就是字幕的缩写不复述
H2演示力5 分：真实界面一步步演到产出物；1 分：用文字卡描述操作能演就演
H3事实诚实5 分：数字可点开核对、示意明确标注；1 分：有编造示意 ≠ 编造
H4品牌一致5 分：只用主题色，强调色一屏一处设计系统用你的
H5节奏与留白5 分：观点时全屏、信息时让位，有呼吸人是内容
H6可读性5 分：手机上一眼可读，字幕始终清楚手机观看
H7剪辑感5 分：像剪辑师切的画面，一屏一事、有焦点；1 分：字墙、空格子、整表「可视化没有之前好了」
自动分
B + C + E + T + S + R

每项通过记 1、提醒记 0.5、失败记 0，取平均 ×100

总分
门槛 × (自动分 × 40% + 人工均分/5 × 60%)

人工占六成：剪辑感只有人看得出来

怎么用

≥ 85 直接发　70–85 修完提醒再发　< 70 返工

自动检查的盲区
  • 剪辑感测不出来。盲测 5 自动分 93，和你喜欢的剪辑师版一样，你的评价却是「好差」。所以版本对比必须并排看成片，不能只看分数。
  • B1 分不清「列举」和「复述」：并列清单天然和原话重合，提醒后人工判断。
  • 元素压脸、图形之间互相遮挡，还要靠拼图人工看。
  • 颜色是否越出主题靠 H4 人工判断。
05

铁律与否决清单

迭代里你明确拍板的，违反就返工

  1. 只加不改：原片画面、声音、时长、镜头顺序一律不动；CTA 也只叠在最后几秒
  2. 卡片不复述口播：关掉声音和字幕，这张图多给了什么？只是同样的字就删
  3. 能演就别写：口播说用某工具做了事，就把真实界面和产出物演出来，不用灰条占位
  4. 示意 ≠ 编造：示意界面标「示意」；数字和来源都要真实检索，不带假热度、假点赞
  5. 不挡脸、不挤：人贴底居中，全屏 / 58% / 50%，不做角落画中画
  6. 皮肤 = 主题：默认你的 Knock〃 设计系统 B 线密度；换主题只换主题文件
  7. 小标题先理结构：通读全文写论证结构，再写「角色词 · 结论」
已否决，不再回头
